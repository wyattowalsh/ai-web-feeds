Welcome to the **ai-web-feeds** documentation. The web app has one canonical entry flow: open `/feeds` for the reader, switch to `/feeds?mode=catalog` to refine sources, keep `/` only as a compatibility redirect, and use `/explorer` as a secondary taxonomy map.

## Start Here

- **Read now:** [`/feeds`](/feeds)
- **Refine sources:** [`/feeds?mode=catalog`](/feeds?mode=catalog)
- **Compatibility redirect:** `/`
- **Taxonomy map:** [`/explorer`](/explorer)

## Product Model

1. Open `/feeds` to browse recent AI articles across all tracked sources.
2. Search the stream first, then narrow to specific feeds, topics, or source types only when you want to focus.
3. Switch to `/feeds?mode=catalog` when you need to inspect or refine the source list directly.
4. Use `/explorer` to inspect topic and feed structure, not as the main reading route.
