## Main Pages

- **`/feeds`** is the main reading surface. It combines the generated article library with catalog filters.
- **`/explorer`** is a visual browser for topics and sources.
- **`/downloads`** exports the catalog in feed-reader-friendly formats.
- **`/stats`** summarizes validation and health information.
- **`/docs`** explains how the project works and how to contribute.

## How the Data Fits Together

- `data/feeds.yaml` is the authored source list.
- `data/topics.yaml` is the topic taxonomy.
- `data/feeds.enriched.yaml` is the generated catalog with richer metadata.
- `data/ai-web-feeds.db` stores runtime data such as fetched entries and validation history.
- `data/articles.generated.json` is the generated article library used by the standalone web app.
