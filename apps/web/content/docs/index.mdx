Welcome to the **ai-web-feeds** documentation. The web app now has one canonical entry flow: open `/` for the reader, switch to `/?mode=catalog` to refine sources, keep `/feeds` only for compatibility with older links, and use `/explorer` as a secondary taxonomy map.

## Product Model

1. Open `/` to browse recent AI articles across all tracked sources.
2. Search the stream first, then narrow to specific feeds, topics, or source types only when you want to focus.
3. Switch to `/?mode=catalog` when you need to inspect or refine the source list directly.
4. Use `/explorer` to inspect topic and feed structure, not as the main reading route.
