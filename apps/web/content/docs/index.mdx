## ✨ Key Features

### 🔎 Search and Reader

- **Source search** - Search the checked-in catalog by title, description, source type, and topic
- **Article search** - Search recent post entries gathered through the aggregate feed loader
- **Built-in reader** - Browse the same recent article corpus with URL-driven filters and local reading state
- **Local-first** - The public search and reader routes work without `BACKEND_URL`

### 📊 Local Analytics

- **Catalog summary** - Total sources, active sources, and recent post counts
- **Topic momentum** - See which topics dominate the current catalog slice
- **Publication velocity** - Inspect recent publishing cadence over time
- **CSV export** - Download the current analytics snapshot

### 📦 Export and Exploration

- **Explorer** - Browse topics and feeds as a graph or table
- **Flat, categorized, and filtered OPML** - Export the whole catalog or a precise visible slice
- **JSON catalog export** - Use the same source registry in scripts or automation
- **Downloads preview** - Inspect bundles before importing them into a feed reader
