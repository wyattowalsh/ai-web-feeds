## Product Model

1. Open `/reader` to browse recent AI articles across all tracked sources.
2. Search the stream first, then narrow to specific feeds, topics, or source types only when you want to focus.
3. Switch to `/sources` when you need to inspect or refine the source list directly.
4. Use `/dashboard` to inspect catalog health; use CLI and repository workflows for OPML, enrichment, and analytics operations.
