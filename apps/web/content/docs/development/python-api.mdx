# Python API

The supported programmatic surface lives at the package root,
`ai_web_feeds`. Start with those imports before dropping down to lower-level
modules.

<Callout type="info" title="Package-first imports">
  Prefer <code>from ai_web_feeds import ...</code> for loading, validation, enrichment, export, configuration, models, and storage access.
</Callout>

## Install and import

```bash
uv sync
uv run python -c "from ai_web_feeds import load_feeds, validate_feeds"
```

## Common workflows

### Load and validate repository data

```python
from pathlib import Path

from ai_web_feeds import load_feeds, load_topics, validate_feeds, validate_topics

feeds = load_feeds(Path("data/feeds.yaml"))
topics = load_topics(Path("data/topics.yaml"))

feed_validation = validate_feeds(feeds, Path("data/feeds.schema.json"))
topic_validation = validate_topics(topics, Path("data/topics.schema.json"))

if not feed_validation.valid:
    raise SystemExit("\n".join(feed_validation.errors))
if not topic_validation.valid:
    raise SystemExit("\n".join(topic_validation.errors))
```

### Enrich a catalog and persist the derived YAML

```python
from pathlib import Path

from ai_web_feeds import DatabaseManager, enrich_all_feeds, load_feeds, save_feeds

feed_doc = load_feeds(Path("data/feeds.yaml"))
db = DatabaseManager("sqlite:///data/ai-web-feeds.db")
db.create_db_and_tables()

enriched = enrich_all_feeds(feed_doc, db=db)
save_feeds(enriched, Path("data/feeds.enriched.yaml"))
```

### Export JSON and OPML artifacts

```python
from pathlib import Path

from ai_web_feeds import export_all_formats, export_to_json, export_to_opml, load_feeds

feed_doc = load_feeds(Path("data/feeds.yaml"))
export_to_json(feed_doc, Path("data/feeds.json"))
export_to_opml(feed_doc, Path("data/feeds.opml"), categorized=False)
export_all_formats(feed_doc, Path("data"), prefix="feeds")
```

### Work with the runtime database

```python
from ai_web_feeds import DatabaseManager

# Uses the canonical SQLite runtime database path
# unless you provide another database URL.
db = DatabaseManager("sqlite:///data/ai-web-feeds.db")
db.create_db_and_tables()

feeds = db.get_all_feed_sources()
print(f"Loaded {len(feeds)} feed sources from the runtime store")
```

## Configuration

`Settings` resolves runtime configuration from `AIWF_*` environment variables.
The most important default for local workflows is the database URL.

```python
from ai_web_feeds import Settings

settings = Settings()
print(settings.database_url)
```

## When to use lower-level modules

The package root is the stable starting point. Drop into submodules only when
you need a narrower concern:

- `ai_web_feeds.load` for catalog canonicalization helpers
- `ai_web_feeds.export` for lower-level export utilities
- `ai_web_feeds.validate` for validation internals and feed URL checks
- `ai_web_feeds.storage` for the full `DatabaseManager` runtime surface
- `ai_web_feeds.analytics`, `ai_web_feeds.search`, and
  `ai_web_feeds.recommendations` for specialized runtime features

## Runtime notes

- The canonical SQLite filename is `data/ai-web-feeds.db`.
- A legacy `data/aiwebfeeds.db` path is still accepted.
- Web routes may also proxy to an external backend service, but the library API
  itself works directly against the core package and database URLs.
