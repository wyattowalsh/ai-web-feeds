The public web app uses two local data sources for search:

- the checked-in catalog for source discovery
- the generated article library for recent-post browsing and post search

## Public Search Surfaces

| Route                        | Backing data                           | Purpose                                       |
| ---------------------------- | -------------------------------------- | --------------------------------------------- |
| `/api/articles`              | `data/articles.generated.json`         | Filtered post browsing with cursor pagination |
| `/api/search?scope=articles` | `data/articles.generated.json`         | Ranked post search                            |
| `/api/search?scope=sources`  | Catalog files under `data/`            | Source discovery                              |
| `/api/search/autocomplete`   | Catalog plus generated article library | Shared suggestions                            |
| `POST /api/search`           | Optional backend proxy                 | Analytics logging only                        |

## Why the Split Exists

The catalog is authored data, so it stays useful even when the runtime database has not been refreshed recently. The generated article library is derived from runtime entries, so it is the right place for browsing and searching recent posts.

## Data Flow

```mermaid
flowchart LR
    authored[data/feeds.yaml + data/topics.yaml] --> enriched[data/feeds.enriched.yaml]
    runtime[(feed_entries in data/ai-web-feeds.db)] --> corpus[data/articles.generated.json]
    enriched --> sourceSearch[/api/search?scope=sources]
    corpus --> articleBrowse[/api/articles]
    corpus --> articleSearch[/api/search?scope=articles]
    enriched --> autocomplete[/api/search/autocomplete]
    corpus --> autocomplete
    articleBrowse --> feeds[/feeds]
    articleSearch --> feeds
    sourceSearch --> feeds
    autocomplete --> feeds
```

<Callout type="info" title="Practical rule">
  If source search still works but post search is empty, check whether `data/articles.generated.json` is missing or stale before changing catalog files.
</Callout>

## Runtime Search Features

The Python runtime still has its own search stack for CLI and backend work, including SQLite FTS, autocomplete indexes, and optional embedding-based search. Those features remain useful operationally, but they are not required for the public `/feeds` experience.

## Commands

```bash
uv run ai-web-feeds corpus refresh
uv run ai-web-feeds corpus export
uv run ai-web-feeds search init
uv run ai-web-feeds search query "llm agents" --type full_text --limit 10
```
