# Analytics & Monitoring

The repository now exposes two analytics surfaces:

- **Web analytics**: local-first read-only metrics that combine the shipped
  catalog with recent aggregate post timestamps
- **CLI/runtime analytics**: commands that operate on the runtime database and
  generated snapshots

<Callout type="info" title="Runtime prerequisite">
  Populate the runtime database first with the load/enrich pipeline before using the CLI analytics commands below.
</Callout>

For the web app, think of the flow as:

1. choose or understand the relevant source slice in `/feeds`
2. inspect current activity in `/analytics`
3. export a full bundle from `/downloads` or a filtered one from the catalog flo

## Common commands

```bash
uv run ai-web-feeds analytics summary --date-range 30d
uv run ai-web-feeds analytics trending --limit 10 --date-range 30d
uv run ai-web-feeds analytics velocity --granularity weekly --date-range 90d
uv run ai-web-feeds analytics snapshot
uv run ai-web-feeds analytics export --output reports/analytics.csv --date-range 30d
```

## What each command does

| Command    | Purpose                                                      | Typical use                          |
| ---------- | ------------------------------------------------------------ | ------------------------------------ |
| `summary`  | High-level runtime metrics and health distribution           | quick status checks                  |
| `trending` | Most active topics over a date range                         | topic discovery and editorial review |
| `velocity` | Validation/publication counts grouped by day, week, or month | cadence analysis                     |
| `snapshot` | Persist a daily analytics snapshot to the runtime store      | recurring reporting                  |
| `export`   | Write analytics CSV output for downstream reporting          | artifacts, spreadsheets, dashboards  |

## Recommended monitoring routine

### Daily

```bash
uv run ai-web-feeds analytics snapshot
uv run ai-web-feeds analytics summary --date-range 7d
```

### Weekly

```bash
uv run ai-web-feeds analytics trending --limit 10 --date-range 30d
uv run ai-web-feeds analytics velocity --granularity weekly --date-range 90d
uv run ai-web-feeds analytics export --output reports/analytics-weekly.csv --date-range 30d
```

## Interpreting the data

- **Summary** shows total sources, active sources, topic counts, and recent post
  activity across the selected window.
- **Trending** ranks topics by recent publication activity over the selected date
  range.
- **Velocity** turns recent publishing activity into time-series data so you can
  spot spikes, gaps, and the most/least active sources.
- **Snapshot** records the current aggregate metrics into the runtime store.
- **Export** produces a CSV artifact you can attach to workflow artifacts or
  load into other reporting tools.

## Runtime data dependency

Analytics are only as good as the runtime database state:

1. Load or process catalog data into SQLite.
2. Run validation and enrichment so feed health fields are current.
3. Generate snapshots/exports from that runtime state.
