Quick reference for common tasks, commands, and endpoints.

## Endpoints

### AI & LLM

| URL                                | Purpose                                  | For         |
| ---------------------------------- | ---------------------------------------- | ----------- |
| `/llms.txt`                        | Discovery file grouped by docs section   | AI agents   |
| `/llms-full.txt`                   | All docs with section + path metadata    | RAG systems |
| `/docs/guides/getting-started.mdx` | Canonical markdown form of one docs page | AI tools    |
| `/docs/guides/getting-started.md`  | Alias for the same markdown payload      | AI tools    |
| `/docs.mdx`                        | Root docs page as markdown               | AI tools    |

<Callout type="info">Prefer `.mdx` in examples and tooling. `.md` is currently an alias route, while content negotiation also rewrites to the `.mdx` handler.</Callout>

### Downloads & Export

| URL                                                     | Purpose                                                    |
| ------------------------------------------------------- | ---------------------------------------------------------- |
| `/feeds`                                                | Primary catalog and subset-selection surface before export |
| `/downloads`                                            | Full-catalog download surface plus optional OPML preview   |
| `/api/exports/opml?format=all`                          | Flat OPML export                                           |
| `/api/exports/opml?format=categorized`                  | Foldered OPML export                                       |
| `/api/exports/opml?format=filtered&feed=<id>&feed=<id>` | Filtered OPML export for an explicit feed-id slice         |
| `/api/feeds`                                            | JSON feed catalog used by the downloads page and explorer  |
| `/api/feeds/posts?feedId=<id>&limit=6`                  | Recent-post preview for one matched feed                   |
| `/api/feeds/posts/aggregate`                            | Merged timeline across visible previewable feeds           |

### RSS Feeds

| URL               | Format    | Content   |
| ----------------- | --------- | --------- |
| `/rss.xml`        | RSS 2.0   | Sitewide  |
| `/atom.xml`       | Atom 1.0  | Sitewide  |
| `/feed.json`      | JSON Feed | Sitewide  |
| `/docs/rss.xml`   | RSS 2.0   | Docs only |
| `/docs/atom.xml`  | Atom 1.0  | Docs only |
| `/docs/feed.json` | JSON Feed | Docs only |

<Callout type="info">
  All feeds are auto-discoverable via `<link>` tags and refreshed hourly. See [RSS Feeds](/docs/features/rss-feeds).
</Callout>

### Content Negotiation

```bash
# Get markdown automatically
curl -H "Accept: text/markdown" https://yourdomain.com/docs/page
```

## Testing Commands

### Test Endpoints

```bash
# Discovery file
curl http://localhost:3000/llms.txt

# Full documentation
curl http://localhost:3000/llms-full.txt

# Root docs page as markdown
curl http://localhost:3000/docs.mdx

# Nested docs page as markdown
curl http://localhost:3000/docs/guides/getting-started.mdx

# Test content negotiation
curl -H "Accept: text/markdown" http://localhost:3000/docs/guides/getting-started
```

### Inspect Headers

```bash
# Check HTTP headers
curl -I http://localhost:3000/llms.txt
curl -I http://localhost:3000/llms-full.txt

# Check custom headers
curl -I http://localhost:3000/llms-full.txt | grep "X-"
```

### Download Content

```bash
# Download full documentation
curl http://localhost:3000/llms-full.txt -o docs.txt

# View table of contents
curl http://localhost:3000/llms-full.txt | \
  sed -n '/Table of Contents:/,/^===/p'

# Count pages
curl http://localhost:3000/llms-full.txt | \
  grep -c "^PAGE [0-9]"

# Download reader import bundles
curl -OJ "http://localhost:3000/api/exports/opml?format=all"
curl -OJ "http://localhost:3000/api/exports/opml?format=categorized"
curl -OJ "http://localhost:3000/api/exports/opml?format=filtered&feed=openai-blog&feed=anthropic-news"
```

## Customization

### Update GitHub URL

Edit `app/docs/[[...slug]]/page.tsx`:

```tsx
githubUrl={`https://github.com/YOUR_ORG/YOUR_REPO/blob/main/apps/web/content/docs/${page.file.path}`}
```

### Add AI Tool

Edit `components/page-actions.tsx`:

```tsx
{
  title: 'Open in MyAI',
  href: `https://myai.com/?url=${markdownUrl}`,
  icon: <MyIcon />,
}
```

### Customize PDF Settings

Edit `scripts/export-pdf.ts`:

```typescript
await page.pdf({
  width: "950px",
  margin: { top: "20px", right: "20px", bottom: "20px", left: "20px" },
});
```

### Modify Discovery File

Edit `app/llms.txt/route.ts`:

```typescript
import { getDocSectionInfo } from "@/lib/source";

const groupedPages = pages.reduce((groups, page) => {
  const section = getDocSectionInfo(page.slugs);
  const existing = groups.get(section.key) ?? { section, pages: [] };
  existing.pages.push(page);
  groups.set(section.key, existing);
  return groups;
}, new Map());

const content = `# Your Custom Title

> Your custom description

## Documentation Pages

${Array.from(groupedPages.values())
  .map(
    ({ section, pages }) => `### ${section.title}

${pages.map((page) => `- [${section.title} / ${page.data.title}](${origin}${page.url}.mdx): ${page.data.description ?? ""}`).join("\n")}`,
  )
  .join("\n\n")}
`;
```

## Common Tasks

### Add New Doc Page

1. Create file in `content/docs/`
2. Add frontmatter with title and description
3. Add the page to `content/docs/meta.json`
4. Write MDX content
5. Spot-check `/llms.txt` or `/llms-full.txt` if the page should be discoverable by AI tooling

### Export PDFs

1. Start dev server: `pnpm dev`
2. Run export: `pnpm export-pdf`
3. Find PDFs in `pdfs/` directory

### Test AI Integration

1. Start dev server: `pnpm dev`
2. Test endpoints with curl (see above)
3. Check page actions in browser
4. Verify content negotiation

### Deploy to Production

1. Build: `pnpm build`
2. Test locally: `pnpm start`
3. Deploy to hosting platform
4. Verify all endpoints work

## Performance Optimization

### Caching Strategy

| Resource         | Cache-Control                |
| ---------------- | ---------------------------- |
| `/llms.txt`      | `s-maxage=86400` (24h)       |
| `/llms-full.txt` | `max-age=0, must-revalidate` |
| `*.mdx` routes   | `immutable` (forever)        |

### Build Optimization

```bash
# Analyze bundle
pnpm build --analyze

# Check bundle size
du -sh .next/

# Clear cache
rm -rf .next/
```
