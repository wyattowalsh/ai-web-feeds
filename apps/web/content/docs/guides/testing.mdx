# Testing Guide

Use the repository root for Python tests and `apps/web` for the web test stack.
The current docs and CI baselines should be described in terms of **`uv run pytest`**
for Python and **`pnpm`** for the web app.

## Quick start

```bash
uv run pytest
uv run pytest -m unit
uv run pytest -m integration
uv run pytest -m "not slow"

pnpm --dir apps/web test:unit
pnpm --dir apps/web test
```

## Python test commands

### Full suite

```bash
uv run pytest
```

### Marker-based runs

```bash
uv run pytest -m unit
uv run pytest -m integration
uv run pytest -m benchmark
uv run pytest -m "not slow"
```

### Target a file or keyword

```bash
uv run pytest tests/tests/packages/ai_web_feeds/test_search.py
uv run pytest -k semantic
```

## Current pytest markers

| Marker        | Meaning                              |
| ------------- | ------------------------------------ |
| `unit`        | fast isolated unit tests             |
| `integration` | multi-component integration tests    |
| `slow`        | tests excluded by `-m "not slow"`    |
| `benchmark`   | performance-oriented benchmark tests |

<Callout type="info" title="Source of truth">
  The marker set above comes from the root <code>pyproject.toml</code>. Keep docs aligned to that file when markers change.
</Callout>

## Web test commands

Run these from the repository root or with `cd apps/web`.

```bash
pnpm --dir apps/web test:unit
pnpm --dir apps/web test
pnpm --dir apps/web test:headed
pnpm --dir apps/web test:ui
```

| Command                           | Runner     | Purpose                          |
| --------------------------------- | ---------- | -------------------------------- |
| `pnpm --dir apps/web test:unit`   | Vitest     | component and library unit tests |
| `pnpm --dir apps/web test`        | Playwright | browser/e2e coverage             |
| `pnpm --dir apps/web test:headed` | Playwright | interactive headed browser runs  |
| `pnpm --dir apps/web test:ui`     | Playwright | Playwright UI mode               |

## Docs-specific checks

When docs, routes, or navigation change, also run:

```bash
pnpm --dir apps/web build
pnpm --dir apps/web lint:links
```
